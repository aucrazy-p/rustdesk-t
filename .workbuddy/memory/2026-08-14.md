## 2026-08-14 托盘隐藏 + CM强制隐藏 + Windows便携版CI

### 完成的修改

#### 1. 主窗口点 X 和最小化都隐藏到托盘
- 文件: `flutter/lib/desktop/pages/connection_page.dart`
- 在 `onWindowClose()` 中追加 `windowManager.hide()` (第292行)
- 在 `onWindowEvent('minimize')` 中追加 `windowManager.hide()` (第261行)
- 主窗口已设 `setPreventClose(true)` (main.dart:112)，点X不退出，现在改为隐藏到托盘
- 点最小化按钮也直接隐藏到托盘，不缩到任务栏
- 托盘图标由 `src/tray.rs` 的 `--tray` 进程管理，Open 菜单可恢复窗口

#### 2. 连接管理窗口(CM)强制隐藏
- 文件: `flutter/lib/main.dart`
- 新增常量 `kForceHideCm = true` (第42行)
- `runConnectionManagerScreen()` 改为强制 `hideCm=true` + `hideCmWindow(isStartup:true)`
- `showCmWindow()` 开头检查 `kForceHideCm`，为true则直接return（空操作）

#### 3. 连接过程不弹CM窗口
- 无需额外文件修改，由需求2自动覆盖

- chat_model.dart 的 `showCmWindow()` 直接调用也被空操作拦截

#### 4. GitHub Actions Windows便携版构建工作流
- 新建文件: `.github/workflows/windows-portable.yml`
- 复用已有可复用工作流: `bridge.yml` (生成桥接文件) + `third-party-RustDeskTempTopMostWindow.yml` (x64)
- 构建命令: `python3 build.py --portable --flutter --skip-portable-pack --hwcodec --vram`
- 产物: `rustdesk-1.4.9-windows-x64-portable.zip`
- 触发: workflow_dispatch + push to main/master
- 关键依赖: Rust 1.75, Flutter 3.24.5, LLVM 15, vcpkg(commit 120deac), rustdesk自定义引擎
